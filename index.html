Pertanyaan
Harus kasih HP-nya langsung?

Tidak harus. Bisa via remote (AnyDesk/TeamViewer) atau saya kirim panduan langkah demi langkah yang Anda ikuti sendiri. Untuk unbrick parah, pengiriman device bisa dibahas.

Device saya merek apa saja bisa?

Semua merek welcome. Yang paling sering saya tangani: Xiaomi keluarga SM6150 (Redmi Note 12 Pro 4G dan sejenisnya), karena di situlah kernel saya bangun. Merek lain tetap bisa — chat dulu untuk memastikan.

Data saya aman gak?

Saya backup sebisa mungkin sebelum eksekusi. Tapi sebaiknya Anda juga backup data penting sebelum mulai, sebagai jaga-jaga.

Pembayaran lewat mana?

DANA atau transfer bank. DP 50% di awal, sisanya setelah selesai dan Anda sudah lihat hasilnya.

Garansinya berlaku untuk apa?

7 hari setelah pengerjaan. Kalau masalah yang sama muncul lagi atau ada error akibat pengerjaan saya, diperbaiki gratis. Tidak berlakal untuk kerusakan fisik atau air.

Kernel custom buat device apa saja?

Terutama device yang kernel source-nya tersedia publik (Xiaomi banyak yang tersedia). Chatkan tipe device + fitur yang Anda mau, saya cek dulu ketersediaan source-nya.
